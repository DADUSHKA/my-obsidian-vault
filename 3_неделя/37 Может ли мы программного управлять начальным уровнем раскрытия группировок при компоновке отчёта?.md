**Да, в системе 1С можно программно управлять начальным уровнем раскрытия группировок** при компоновке отчёта. [koderline.ru](https://www.koderline.ru/expert/narabotki/article-programma-1s-uroven-gruppirovok/)

Для этого используют методы «ПоказатьУровеньГруппировкиСтрок()» и «ПоказатьУровеньГруппировкиКолонок». Они раскрывают группировки, которые имеют уровень меньше переданного в метод значения (нумерация начинается с нуля). Также метод закрывает те группировки, уровень которых равен переданному, у тех, которые имеют уровень больше, — всё остаётся без изменений. [koderline.ru](https://www.koderline.ru/expert/narabotki/article-programma-1s-uroven-gruppirovok/)

Чтобы скрыть все группировки до конкретного уровня, нужно вызвать метод «ПоказатьУровеньГруппировокСтрок()» внутри цикла и по порядку закрывать все уровни до необходимого. [koderline.ru](https://www.koderline.ru/expert/narabotki/article-programma-1s-uroven-gruppirovok/)
