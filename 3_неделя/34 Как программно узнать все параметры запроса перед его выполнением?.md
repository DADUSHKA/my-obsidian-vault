**Узнать параметры запроса (текст результирующего SQL-запроса), сгенерированного системой компоновки данных (СКД) в 1С, программно можно через отладчик или консоль СКД**. Эти инструменты позволяют увидеть запрос непосредственно перед его выполнением и проанализировать параметры. [dzen.ru](https://dzen.ru/a/aEd8k032L0xb_sYj)[implecs.ru](https://implecs.ru/about-us/blog/skd/)[1s-up.ru](https://www.1s-up.ru/otladka-otcheta-na-skd-pri-pomoshhi-konsoli-firmy-1s/)

## Через отладчик

**Рекомендуется, если есть возможность отладки**: [dzen.ru](https://dzen.ru/a/aEd8k032L0xb_sYj)

1. **Установить точку останова** в модуле объекта отчёта (или обработке, формирующей отчёт). Найти место, где вызывается метод 
    
    СкомпоноватьРезультат()
    
     объекта «КомпоновщикМакетаКомпоновкиДанных» (или «ПроцессорКомпоновкиДанных»).
2. **Запустить отчёт в режиме отладки** (меню «Отладка» → «Начать отладку»). Открыть отчёт и сформировать его. Когда выполнение программы достигнет точки останова, 1С остановится.
3. **Получить текст запроса**:
    - В окне отладчика найти объект «КомпоновщикМакета» (или «ПроцессорКомпоновкиДанных»).
    - Найти свойство **«ТекстЗапроса»** (или аналогичное, в зависимости от версии 1С и типа компоновщика). Значение этого свойства содержит текст результирующего SQL-запроса.
    - Скопировать этот текст в текстовый редактор или в консоль запросов для дальнейшего анализа.

 [dzen.ru](https://dzen.ru/a/aEd8k032L0xb_sYj)

**Важно**:

- В некоторых случаях на отображение результирующего запроса может влиять режим совместимости базы данных.
- 1С может кэшировать результаты запросов СКД — если изменён макет СКД, но результирующий запрос не изменился, стоит очистить кэш 1С.

 [dzen.ru](https://dzen.ru/a/aEd8k032L0xb_sYj)

## С помощью кода

- **Использовать функцию «НайтиПараметры»** объекта «Запрос». Она возвращает список параметров в запросе, включая их имена и типы. Например, для запроса вида «ВЫБРАТЬ Банки.Наименование, Банки.Город, Банки.Адрес ИЗ Справочник.Банки КАК Банки ГДЕ Банки.Город = &Город» функция «НайтиПараметры» возвращает имя параметра («Город») и его тип.
- **Реализовать функцию, которая выводит список параметров** и тип, а затем получает значения параметров. Например, в классе, обрабатывающем запросы к 1С, можно реализовать функцию, которая получает запрос, выводит список параметров и тип, а затем получает значения параметров и подставляет их в запрос.

## Через API

**Консоль СКД** позволяет посмотреть текст запроса и значения параметров. **Чтобы узнать, какой запрос был сформирован схемой компоновки данных**, нужно: [infostart.ru](https://infostart.ru/1c/articles/1600909/)[1s-up.ru](https://www.1s-up.ru/otladka-otcheta-na-skd-pri-pomoshhi-konsoli-firmy-1s/)

1. Сохранить схему СКД в виде файла XML.
2. В запущенной консоли СКД добавить отчёт и загрузить в него сохранённую схему компоновки данных.
3. В нижней части консоли перейти на вкладку **«Макет для табличного документа XML»** и в разметке XML найти запрос (он единственный).

 [1s-up.ru](https://www.1s-up.ru/otladka-otcheta-na-skd-pri-pomoshhi-konsoli-firmy-1s/)

**Важно**: запрос в консоли СКД может отличаться от запроса, который сформировал разработчик при создании отчёта на СКД, — часто запрос, генерируемый СКД, и запрос, который сформировал разработчик, могут не совпадать. [1s-up.ru](https://www.1s-up.ru/otladka-otcheta-na-skd-pri-pomoshhi-konsoli-firmy-1s/)
