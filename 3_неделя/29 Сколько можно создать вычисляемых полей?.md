==**Не существует ограничения на количество вычисляемых полей== в системе компоновки данных (СКД) 1С**. [softmaker.kz](https://softmaker.kz/skd/sistema-komponovki-dannyx-skd-chast-4.html)[sites.google.com](https://sites.google.com/site/1sspravocniktipovyhzadac/%D1%81%D0%BA%D0%B4/%D0%B2%D1%8B%D1%87%D0%B8%D1%81%D0%BB%D1%8F%D0%B5%D0%BC%D1%8B%D0%B5-%D0%BF%D0%BE%D0%BB%D1%8F)

Вычисляемые поля — это дополнительные поля схемы компоновки, значения которых рассчитываются на основании основных полей компоновки (полей наборов данных). Их можно создавать, чтобы использовать поля из различных наборов данных, выполнять операции над полями наборов данных типа «объект» и для других целей. [infostart.ru](https://infostart.ru/1c/articles/1082572/)[its.1c.ru](https://its.1c.ru/db/metod8dev/content/1810/hdoc)

==Однако есть ограничение:== в выражении вычисляемого поля **нельзя использовать другие вычисляемые поля**. В выражении можно использовать все синтаксические конструкции языка выражений, поля наборов данных и функции общих модулей конфигурации. [infostart.ru](https://infostart.ru/1c/articles/1082572/)[its.1c.ru](https://its.1c.ru/db/metod8dev/content/1810/hdoc)[sites.google.com](https://sites.google.com/site/1sspravocniktipovyhzadac/%D1%81%D0%BA%D0%B4/%D0%B2%D1%8B%D1%87%D0%B8%D1%81%D0%BB%D1%8F%D0%B5%D0%BC%D1%8B%D0%B5-%D0%BF%D0%BE%D0%BB%D1%8F)
