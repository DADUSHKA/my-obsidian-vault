**Объединение** соединяет таблицы горизонтально, то есть получает не новые поля, а новые строки. Используется, когда нужно выбрать данные из двух никак не связанных таблиц. [wiki-1c.ru](http://wiki-1c.ru/doku.php/1c:%D0%B1%D0%B0%D0%B7%D0%B0:%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D1%8B)

Результатом выполнения объединения запросов будет <span style="color:rgb(192, 0, 0)">слияние двух результатов вместе</span>. То есть данные будут получены по обоим запросам, но соединены в одно. К примеру, по следующим данным

**Соединение** (правое, левое)позволяет получить в одной строке результата запроса данные из нескольких таблиц, связав их между собой. Почти всегда указывается условие, по которому система сопоставит данные из одной таблицы с данными из другой таблицы. [wiki-1c.ru](http://wiki-1c.ru/doku.php/1c:%D0%B1%D0%B0%D0%B7%D0%B0:%D0%B7%D0%B0%D0%BF%D1%80%D0%BE%D1%81%D1%8B)

Таким образом, **основное отличие** в том, что **объединение объединяет данные, а соединение — связывает их**, формируя одну общую таблицу, в которой данные из разных таблиц объединяются по определённому условию.
