**Ускорить выполнение запроса в «1С:Предприятии» можно, не исправляя его текст, но оптимизировав структуру запроса, используя индексы и, в некоторых случаях, временные таблицы**.

## Индексация

- **Создать индексы** для полей, которые часто участвуют в условиях отбора и соединениях. При этом важен порядок полей в индексе: он работает эффективно, только если условие начинается с первого поля. [sectorsystem.by](https://sectorsystem.by/info/articles/vse-dlya-1s/optimizatsiya-zaprosov-1s-pochemu-tormozit-otchet-i-kak-eto-ispravit/)
- **Использовать индексы в условиях отбора** — условия должны использовать поля, по которым созданы индексы. Запросы с условиями по индексированным полям выполняются быстрее, чем по неиндексированным. [dzen.ru](https://dzen.ru/a/Z8Nz7k8b8iEw8bkq)
- **Избегать избыточных индексов** — не нужно индексировать все поля подряд, это увеличивает время записи данных. [nweb42.com](https://nweb42.com/books/1c/optimizatsiya-zaprosov-1c/)

## Временные таблицы

- **Разбить сложный запрос на несколько последовательных шагов** — сначала отобрать нужные данные во временную таблицу, затем создать для неё индексы и уже потом, на облегчённых данных, выполнять сложные соединения и группировки.
- **Проиндексировать созданную временную таблицу** — индекс должен быть подобран так, чтобы СУБД могла его использовать при соединении с временной таблицей. В индексе должны быть перечислены все поля, которые используются в условии соединения.
