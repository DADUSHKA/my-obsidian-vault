[# Хранилище настроек](https://master1c8.ru/platforma-1s-predpriyatie-8/rukovodstvo-razrabottchika/glava5-obaekt-kogfiguratsii/1837/)

Пользовательские настройки отчётов в 1С хранятся в **хранилище «Пользовательские настройки отчётов»**. [master1c8.ru](https://master1c8.ru/platforma-1s-predpriyatie-8/rukovodstvo-razrabottchika/glava5-obaekt-kogfiguratsii/1837/)[wiseadvice-it.ru](https://wiseadvice-it.ru/o-kompanii/blog/articles/hranilishhe-nastroek-v-1s-8-3/)

Также настройки отчётов могут храниться **в специальном объекте информационной базы**, например, в справочнике или регистре сведений. [master1c8.ru](https://master1c8.ru/platforma-1s-predpriyatie-8/rukovodstvo-razrabottchika/glava5-obaekt-kogfiguratsii/1837/)

Место хранения каждого отчёта можно подобрать индивидуально при разработке конфигурации, указав в свойствах, что определённая база будет использоваться для записи настроек отчётов. [it-rush.ru](https://it-rush.ru/blog/gde-hranitsya-nastroiki-otchetov/)




Платформа 1С использует 5 основных хранилищ форм:

1. Системное – база где хранятся настройки отчетов, необходимых для работы программы (размеры форм, печать файлов). Хранилище применяется в качестве «стандартного» и сохраняет сведения в таблицах информационной базы;
2. Общее — используется разработчиком для записи и восстановления прикладных настроек. Сама программа не записывает информацию в это хранилище;
3. Для хранения вариантов отчетов;
4. Непосредственно хранилище 1С где хранятся настройки отчетов пользователя. Здесь вы найдете сохраненные пользовательские формы;
5. Для настроек данных форм. Подходит для использования, если необходимо сохранить реквизиты обработок. Место хранения каждого отчета можно подобрать индивидуально – это упростит работу с 1С.

Выбрать хранилища для выгрузки файлов можно при разработке конфигурации. Для этого в свойствах пользователь указывает, что определенная база будет использоваться для записи настроек отчетов. Так вы сможете грамотно организовать работу с едиными формами. То, каким образом будет определяться объект хранилища, определяет разработчик – выбирая и настраивая нужные параметры.

## Где хранятся настройки внешних отчетов 1с

Внешние формы не входят в число прикладных и сохраняются в отдельных файлах. Любой уже созданный отчет можно настроить следующим образом:

- Преобразовать во внешний и наоборот.
- Добавить в структуру прикладных решений под новым именем.

Где хранятся настройки внешних отчетов 1с – определенные ограничения системы не позволяют таким обработкам использовать формы управляемого приложения. Для удобства данные сохраняются в справочнике и встраиваются в конфигуратор. Дополнительно рекомендуется добавить нужную форму отчета и прописать варианты событий: «Перед сохранением» и «После восстановления значений».
